# About

The tinygo_uefi repo holds experiments in writing UEFI applications with tinygo.  It's currently setup to work with QEMU on MacOS.

## setup

* Needs make, QEMU, and tinygo installed with homebrew
* Run  `make run` to build the environment, the UEFI binary, and start the VM.  
* `make clean` will remove local directory changes
